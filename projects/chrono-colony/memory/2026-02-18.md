## Architecture decisions
- Went fully programmatic (no storyboards) — cleaner, avoids IB version issues
- XcodeGen for project file generation — `.xcodeproj` not in git
- 10x10 grid (not 12x12 from GDD) — testing tap targets on mobile first
- Seeded RNG via xorshift64 — deterministic runs from the start
